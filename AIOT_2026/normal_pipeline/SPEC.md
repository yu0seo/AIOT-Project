# 구현 기준

사용자 요청: 기존 Windows AIR-400 추론 코드를 유지하고 공식 데이터를 내려받아 정상 호흡 이상 탐지용 학습 입력을 구축한다.

- AIR_125/Sxx와 AIR_400/Sxx를 별도 영아로 식별한다.
- 영상과 HDF5 실제 구조/키/시간축을 검사하고 누락/짧은 파일을 보고한다.
- 영상과 정답 파형을 사람이 확인하고 정상 구간, 품질, 정렬을 명시적으로 승인해야만 사용한다.
- 기존 로컬 PreProcessor, InferenceDataset, infer.run_inference, DeepPhys 체크포인트를 재사용한다. 원본은 수정하지 않는다.
- 각 30초 프레임 버퍼에 독립적으로 전처리와 추론을 적용하고 5초 간격으로 갱신한다. 원본 전체를 먼저 필터링하지 않는다.
- 불완전한 추론 길이를 30초로 늘리지 않는다. 모델 내부 chunk 절단으로 길이가 부족해지면 제외한다.
- 10Hz polyphase 리샘플링, (N,1,300) float32 저장. 추가 정규화 계수는 train에서만 추정한다.
- 분할은 영아별로 고정한다. 승인/파일 변경 및 중복 파일을 검사한다. 사전학습 추론기에서의 영아 누수는 별도로 기록/검사한다.
- 원시 모델 출력과 기존 후처리 출력을 모두 보존한다. 실제 서비스는 제공한 동일 adapter와 normalization을 호출한다.
- 실제 정상/비정상 승인과 이상 탐지 모델의 학습/임상 성능 평가는 자동으로 대체하지 않는다.

검증 순서: 자료 구조/경계조건 테스트 → 실제 다운로드/검사 → 실제 체크포인트로 30초 추론 → 공통 경로 일치 테스트 → 한국어 안내 및 압축 파일.
