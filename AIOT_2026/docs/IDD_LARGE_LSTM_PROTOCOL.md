# LSTM 크기 확대 비교 기준

사용자의 모델 크기 확대 요청에 따라 실제 학습으로 비교한다. 기존 가중치와 데이터는 보존한다.

| 모델 | hidden | 층 수 | 파라미터 |
|---|---:|---:|---:|
| 이전 요약 LSTM | 32 | 1 | 4,993 |
| 확대 후보 1 | 64 | 2 | 51,457 |
| 확대 후보 2 | 128 | 2 | 201,217 |
| 확대 후보 3 | 256 | 3 | 1,321,985 |

- 입력 피처, 단위와 순서, 10Hz, 3/5/10초 입력, 7점 인과적 평활화, 로그 정규화, 시점 요약은 이전 선택 후보와 동일하다. 모델 너비와 층 수를 확대한다. Dropout 0.1은 분류기 앞과 다층 LSTM의 층 사이에 적용된다.
- 기존 train 12명 안에서 같은 seed와 같은 3-fold로 비교한다. 각 fold의 train 데이터로만 정규화한다. validation 4명과 test 4명은 후보 탐색에서 사용하지 않는다.
- 3개 크기 × 3개 입력 길이 × 3개 fold로 27회 학습한다. 최대 40 epoch, patience 7, 참가자 macro AUC 기준 checkpoint를 사용한다.
- 이전 실험과 같은 끝 시각에서 비교하도록 `comparison_warmup_points=21`을 고정한다. 이는 실제 평활화 점 수 7을 바꾸는 설정이 아니며, 비교 Window의 초기 기준 시각만 맞춘다.
- 이전 32×1 대조군은 이미 같은 조건으로 학습한 `outputs/idd_improvement_cv`의 fold 예측과 점수를 사용한다. fold ID와 Window 끝 시각이 일치하는지 검사하며 불필요한 재학습은 하지 않는다.
- 길이별 확대 후보는 평균 CV macro AUC, 평균 CV macro recall, 적은 파라미터 순으로 선택한다. 세 확대 후보만 순위를 매기며 이전 작은 모델과의 우열은 별도로 보고한다.
- 선택한 확대 후보를 train 12명으로 stride 1초 재학습하고 validation 4명으로 checkpoint와 임계값을 정한다. 기본 임계값은 validation Window FPR≤5% 기준이다. 모든 선택을 고정한 뒤 test를 한 번 평가한다.
- 기존 test 결과가 이미 알려진 반복 연구이므로 완전히 새로운 외부 검증으로 주장하지 않는다. 큰 모델의 train 성능과 새 참가자 성능을 구분하고 test 결과를 보고 후보를 바꾸지 않는다.
- 실행 환경은 CPU이며 새 라이브러리를 도입하지 않는다. 큰 모델의 가중치와 공통 추론 모듈의 호환성도 확인한다.
