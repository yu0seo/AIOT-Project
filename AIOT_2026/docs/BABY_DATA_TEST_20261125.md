# 로컬 아기 데이터와 정지 인형 비교 시험

실행일: 2026-11-25, 한국 시간. 현재 `AIOT_2026` 루트의 기존 모델을 재사용했다. 모델·임계값·전처리·운영 설정/진행 상태는 변경하지 않았다.

## 범위와 라벨 근거

- `data/AIR_125`에 MP4 99개, `data/AIR_400`에 MP4 295개가 있다. 이번 새 영상 추론은 데이터셋을 포함한 영아 ID 6개의 첫 30초씩만 실행했다. 전체 394개 영상을 새로 추론한 것은 아니다.
- 기존 `output/training_30s/windows`의 추출 파형 773구간도 현재 v2로 재점수화했다. 기존 파형 재점수화와 새 영상 추론을 구분한다.
- `normal_data/approvals.json`의 승인 구간은 0개다. 선택 영상의 manifest 상태는 `pending_review`, 기존 학습 파형의 라벨은 `unreviewed`다. 사용자가 정상 데이터로 지칭한 집합이며, 정상 정답이 검증된 임상 성능 평가가 아니다.
- `AIR_125:S01`과 `AIR_400:S01`은 구분했다. 기존 train/valid/test를 보존했고 재학습하지 않았다.

## 새 영상 추론 결과

각 원본의 첫 30초를 별도 H.264/CRF18 영상으로 준비했다. 수집기의 `ExistingPipeline.analyze`와 같은 경로로 ROI 활성, frame batch 16, 15Hz/450프레임, 후처리 10Hz/300점을 사용했다. 임계값은 기존 `1.0177805423736572`다.

| 영상 | 기존 split | 추정 BPM | 이상 점수 | 상태 |
|---|---|---:|---:|---|
| AIR_125_S01_001 | train | null | null | unscored: ROI 미검출 |
| AIR_125_S02_001 | valid | 21.09375 | 0.02880848 | below_threshold |

새 아기 영상은 임계값 이하 5개, 분석 불가 1개다. 분석 불가를 정상으로 변환하거나 ROI를 꺼서 통과시키지 않았다. S09 영상은 v2 학습과 임계값 설정에서 제외된 test 영아의 영상이다.

## 기존 파형 773구간 재점수화

| 기존 split | 임계값 이하 | 이상 후보 | 분석 불가 |
|---|---:|---:|---:|
| train | 533 | 5 | 0 |
| valid | 194 | 1 | 0 |
| test | 40 | 0 | 0 |

합계 임계값 이하 767개, 이상 후보 6개다. test 40개는 AIR_400:S09의 기존 파형이다. train은 학습에, valid는 임계값 설정에 사용된 데이터이므로 세 집합을 합친 비율을 일반화 성능으로 보고하지 않는다. 미검토 라벨 때문에 이 집계는 임상 오탐률도 아니다.

## 해석과 남은 검증

- 같은 추론 경로의 아기 점수 중 정지 인형보다 낮은 값과 높은 값이 모두 있다. 이번 표본에서 기존 점수의 단일 임계값 변경만으로 호흡 부재를 분리할 수 없다.
- 후처리 파형이 진동하거나 양수 BPM이 나온다는 사실은 호흡 신호 존재의 증거가 아니다. 호흡 유무/신호 품질 검증은 기존 파형 복원 점수와 별도로 필요하다.
- 같은 영상에서도 기존 추출 파형 점수와 새 영상 점수는 달랐다. 원본 추출기와 생산 경로의 FPS/chunk/frame batch 차이를 그대로 기록했으며 동등성을 가정하지 않는다.
- 데이터셋 아기 영상과 인형의 촬영 조건은 다르다. 같은 카메라·거리·조명에서 규칙적 흉곽 움직임을 모사한 비교 영상은 여전히 없다. 이 대조군과 정지/카메라 변화 사례로 기준을 검증해야 한다.
