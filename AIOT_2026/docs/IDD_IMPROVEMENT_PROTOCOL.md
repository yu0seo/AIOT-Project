# 성능 개선 실험 기준

실험 전에 고정한 비교 계획이다. 기존 baseline과 원본 데이터는 보존한다.

- 입력은 기존 speed/acceleration/jerk/turn_rate 네 개와 10Hz, 3/5/10초를 유지한다.
- 기존 train 참가자 12명 안에서 3-fold 참가자 교차검증으로 9개 후보를 비교한다. 같은 참가자와 겹치는 Window가 서로 다른 분할에 들어가지 않는다.
- 후보는 `configs/idd_search.json`으로 고정한다. 새 라이브러리는 도입하지 않는다.
- 비교 대상은 마지막 상태 LSTM, 전체 시점의 last/mean/max/std를 내부 표현으로 요약하는 LSTM/GRU, 인과적 dilated Conv1d TCN이다. 내부 요약은 신경망의 읽기 방식이며 새 외부 입력 피처를 추가하지 않는다.
- 큰 미분값의 영향을 줄이기 위해 `sign(x)*log1p(abs(x))` 이후 train 기준 평균/표준편차 정규화 후보를 둔다. 원시 네 특징의 정의·단위는 그대로이며, 동일한 변환을 추론에서도 사용한다. clipping이나 위험 구간 삭제는 하지 않는다.
- 평활화 점 수 7/11/21을 비교한다. 미래 관측을 사용하는 필터는 도입하지 않는다. 서로 다른 평활화 후보도 동일한 raw 끝 시각의 Window를 사용한다.
- 탐색은 3초 stride, 최대 40 epoch, patience 7, 참가자 macro AUC 기준 checkpoint를 사용한다. 기준 모델도 같은 탐색 조건으로 다시 평가한다.
- 길이별 후보 선택 순서는 평균 fold 참가자 macro AUC, 평균 fold 참가자 macro recall(FPR 5% 임계값), 적은 파라미터다. fold 점수는 모델 선택용이며 선택 이후의 비편향 성능 추정치로 주장하지 않는다.
- 선택 후보를 기존 train 12명으로 stride 1초 재학습한다. 기존 validation 4명은 early stopping과 임계값 결정에 사용한다. 저오탐 임계값은 기존과 같이 validation Window FPR≤5%를 따른다. balanced accuracy 최대 임계값은 별도의 보조 결과로 저장하며 기본 관제 임계값을 대체하지 않는다.
- 후보/길이/임계값을 고정·저장한 후 기존 test 4명을 한 번 평가한다. 같은 끝 시각의 기존 예측과 짝지어 비교하고 참가자 군집 bootstrap 차이 구간을 계산한다.
- 기존 test 결과를 이미 본 후 시작한 후속 연구이므로 이 test는 완전히 새로운 외부 검증이 아니다. 선택 뒤 test 성능이 낮아도 이를 보고 후보를 다시 선택하지 않는다. 실제 CCTV 또는 새로운 참가자 데이터가 최종 외부 검증에 필요하다.
- 개선이 확인되지 않으면 개선 실패도 그대로 보고하며 기존 best를 덮어쓰지 않는다.
