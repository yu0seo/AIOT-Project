# 소형 InceptionTime 동일 5-fold 실제 비교 결과

실제 IDD CSV로 측정했다. 인공 fixture 결과와 중단된 GPU 시험의 수치는 포함하지 않는다.

이번 소형 설정에서는 MiniRocket 대비 개선을 확인하지 못했다. 세 길이 모두 pooled AUC와 균형 임계값 정확도가 낮았다. 10초 모델은 AUC 0.5973/정확도 57.29%였고, MiniRocket은 0.6442/60.70%였다. 소형 InceptionTime의 저오탐 설정은 FPR 5.11%, Recall 11.68%다. 현재 네 피처 조건의 연구 기준 모델은 MiniRocket 10초를 유지하는 쪽이 타당하다.

- 참가자 20명, no_task 주행 75개, 길이별 테스트 OOF Window 14,190개.
- MiniRocket과 동일한 바깥 5-fold/안쪽 참가자 3-fold, 동일한 CSV 해시와 평가 행을 확인했다.
- 네 입력 speed/acceleration/jerk/turn_rate, 10Hz, 과거 7점 평활화, signed_log1p, train 정규화 유지.
- 모델은 단일 소형 InceptionTime, 파라미터 56,513개, 16필터, bottleneck 16, 3모듈, 커널 39/19/9, dropout 0.3이다.
- CPU/PyTorch 2.15.0에서 측정했다. GPU 장기 실행 지연으로 바깥 테스트 전에 중단하고 동일 CPU 환경의 완료 내부 모델을 복구했다.
- 최종 모델/내부 모델 60개 학습 이력의 epoch 시간 합 61.8분. 최종 재개 실행 구간 58.6분이며 이전 GPU 준비/중단 시간은 제외된다.

## 참가자별 일반화와 짝지은 비교

| 입력 | InceptionTime 참가자 macro AUC | 95% 구간 | mean fold AUC | MiniRocket 대비 macro AUC 차이 | 차이 95% 구간 |
|---|---:|---|---:|---:|---|
| 3초 | 0.5651 | 0.5303–0.6030 | 0.5693 | -0.0162 | -0.0370–0.0030 |
| 5초 | 0.5720 | 0.5374–0.6071 | 0.5757 | -0.0275 | -0.055085–+0.000006 |
| 10초 | 0.5987 | 0.5591–0.6405 | 0.6049 | -0.0426 | -0.0667–-0.0200 |

각 모델의 구간은 참가자 군집 bootstrap 1,000회다. 모델 차이는 같은 20명의 AUC 차이를 짝지어 bootstrap 10,000회 계산했다. 고정된 OOF 예측의 사후 비교이며 모델 재학습 변동 전체를 포함하지 않는다. pooled AUC는 모델 사이 점수 눈금 차이에 영향받을 수 있어 참가자 macro AUC를 함께 해석한다.

3초/5초 모델 차이의 구간은 0을 포함하므로 그 우열을 단정하지 않는다. 10초 차이의 구간은 음수였고, 이번 고정 OOF 예측에서는 MiniRocket의 참가자별 분리도가 더 높았다. 반복 연구의 사후 비교라는 한계는 그대로 남는다.

## 검증과 저장

- 소프트웨어 테스트 42개 통과. 네 피처/세 입력 길이의 gradient, 저장/온라인 추론, 동일 fold/Window, 완료 내부 모델 복구를 포함한다.
- 참가자 20명은 각 한 번만 바깥 테스트에 들어갔고, 모든 시나리오/겹치는 Window는 참가자와 함께 분리했다.
- 원본 CSV 75개 해시, 내부 45개/바깥 15개 정규화, 내부 train Window 수와 중앙값 재학습 epoch를 실제 데이터에서 재계산해 확인했다.
- 최종 15개 모델 모두 실제 CSV 재생의 테스트 Window 3개씩을 비교했다. 최대 점수 차이 8.95e-08로 float32 수치 오차 범위에서 일치했다.
- 번들: `outputs/idd_inceptiontime_5fold_cpu_v1/fold_1/3s` 등. `model.pt`와 `metadata.json`에 가중치/피처 정의/정규화/길이/샘플링/평활화/임계값이 있다.
- 전체 수치: 같은 폴더의 `report.json`, `comparison.csv`, `metrics_*s.json`, `oof_*s.csv`, `paired_model_comparison.json`, `independent_verification.json`.

## 비교 해석의 범위

바깥 학습/테스트 참가자, 최종 학습 Window와 평가 Window가 MiniRocket과 동일하다. InceptionTime의 내부 학습은 stride 1초, MiniRocket 내부 학습은 stride 3초이므로 튜닝 시 학습 밀도에는 차이가 있다. 내부 validation은 두 모델 모두 stride 3초다. 평가 데이터의 운전자나 종료 시각을 바꾸어 얻은 차이는 아니다.

이번 고정 설정의 소형 단일 네트워크 결과다. 원 논문의 다중 네트워크 ensemble이나 모든 InceptionTime 설정의 성능으로 일반화할 수 없다. 같은 IDD에서 반복 비교한 연구이므로 새로운 외부 검증도 아니다.

IDD 실험 조건 분류 수치가 실제 CCTV 음주 탐지 정확도를 의미하지 않는다. Window FPR과 차량 경보 FPR을 구분하고, 10초 입력은 약 10.5초 연속 유효 추적이 필요하다는 점도 함께 판단해야 한다. 학습/추론 방법은 [실행 안내](IDD_INCEPTIONTIME.md)를 참고한다.
