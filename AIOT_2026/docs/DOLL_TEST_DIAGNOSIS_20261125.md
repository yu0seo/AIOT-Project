# 인형 시험의 이상 미검출 진단

확인일: 2026-11-25. 대상: `babycam-session-1`, TS 80~94, 결과 저장 시각 18:37:06 KST.

## 실제 결과와 입력

- 저장 결과: `below_threshold`, BPM `29.8828125`, 이상 점수 `0.00707743875682354`, 임계값 `1.0177805423736572`.
- 파형 MSE `0.005848108325153589`, BPM MSE `0.006146651227027178`. 기존 체크포인트로 재계산한 총점은 동일했다. 표시/CSV bool 변환 오류로 확인된 것은 아니다.
- 직전 65~79 구간은 ROI 검출 실패로 `unscored`였다. 분석 불가를 정상으로 해석하지 않는다.
- 사용자는 80~94가 카메라·인형 모두 고정된 시험이라고 설명했으나, **실제 결합 영상에는 약 5~15초에 손으로 인형을 회전시키는 장면이 있다.** 1초에는 정면, 6초에는 손이 접근, 8/12초에는 인형을 돌리고, 16/24초에는 옆으로 놓인 상태다. 따라서 이 파일은 순수한 정지 30초 음성 대조군이 아니다.
- 수집기는 가장 오래된 연속 TS부터 처리하고 결과 저장 시각은 촬영 시각이 아니다. 실시간 화면과 처리 대상 구간이 달라졌을 가능성이 있으며 촬영 timestamp 대응은 아직 검증되지 않았다.

## 코드에서 확인한 구조적 한계

1. `PreProcessor`는 채널별 입력/Optical Flow를 표준화한다. 정규화된 값과 DeepPhys 출력 크기를 물리적 호흡량으로 해석할 수 없다. 원시 출력도 신경망의 출력이며 원본 영상의 절대 움직임과 같지 않다.
2. `DeepPhysRunner.extract`는 원시 신호를 누적합·detrend·0.3~1Hz bandpass 후 FFT로 처리한다. FFT 함수는 그 범위에서 최대 주파수를 선택하며 호흡 신호 존재/잡음 기준을 먼저 확인하지 않는다.
3. 실제 저장 파형의 큰 진동은 손 조작 구간과 겹친다. 영상 전체에서 계산한 BPM 하나는 후반 정지 구간의 호흡 존재를 증명하지 않는다.
4. v2 점수는 `wave_mse + 0.2 * bpm_mse`다. 입력 파형을 잘 복원하는지가 호흡 존재 또는 무호흡 여부를 직접 보장하지 않는다. 현재 원시 움직임의 소실을 별도로 검증하는 분기는 없다.

진단용 합성 신호 실험(임상/영상 평가가 아님):

- 거의 평평한 파형(std 약 `7.07e-6`)에 저장된 양수 BPM을 주면 총점 약 `0.1010`으로 현재 임계값보다 낮다.
- `_calculate_fft_rr` 함수 단독에 정확한 0 신호 450점을 주면 약 `19.3359` BPM이 나온다. 상위 추론기에는 완전 상수 원시 출력 거절이 있으므로 이 단독 실험을 실제 전체 파이프라인 결과로 혼동하지 않는다. 이는 FFT 함수 자체가 신호 존재를 판정하지 않는다는 재현이다.
- 기존 검증 CSV의 중앙 점수는 약 `0.03642`이며, 인형 점수보다 낮은 구간은 195개 중 1개뿐이다. 임계값을 인형 점수보다 조금 낮추면 정상으로 **가정된 미검토** 검증 구간 194/195개가 이상 후보가 된다. 한 실패 사례에 맞춘 임계값 변경의 근거로 사용하지 않는다.

## TS 88~102 정지 구간 재시험

사용자가 88번부터 인형을 만지지 않았다고 알려 주어, 실제 Storage의 서로 다른 연속 TS 88~102번 15개를 내려받고 기존 파이프라인으로 단일 배치를 실행했다. 결과 저장 시각은 2026-11-25 18:54:37 KST다.

- 입력: 30초 결합 영상, 10 FPS, 300프레임. 1/6/12/18/24/29초 대표 프레임에 손 조작이 없고 인형 자세가 동일하다. 전체 인접 회색조 프레임의 평균 절대 차이는 중앙값 `0.05842`, 95백분위 `0.28504`, 최대 `0.41578`이다. 이 지표는 영상 변화가 작음을 보여 주지만 카메라 잡음과 실제 미세 움직임을 분류하는 기준은 아니다.
- 실제 결과: `below_threshold`, BPM `29.8828125`, 이상 점수 `0.04436233639717102`, 임계값 `1.0177805423736572`. 파형 MSE `0.022292522713541985`, BPM MSE `0.11034907400608063`, 배치 처리 시간 `42.422`초.
- 손 조작을 제외한 구간에서도 호흡 없는 인형에 양수 BPM과 임계값 이하 결과가 나왔다. 앞 시험의 손동작만으로 미검출을 설명할 수 없다. 후처리 파형이 진동한다는 사실만으로 호흡 신호 존재를 인정할 수 없다는 한계가 재현됐다.
- 실험 세션 `doll-fixed-retest-88-102`와 별도 작업/결과 폴더를 사용했다. 운영 `.env`, 작업 커서, 모델과 임계값은 변경하지 않았다. Supabase에는 입력 영상을 읽는 작업만 수행했다.

구간 선택은 모델에 전달하는 순서 옵션이 아니라 수집기의 `START_SEQ` 설정이다. `START_SEQ=88`이면 88~102를 구성하고, 지속 실행 시 다음은 103~117이다. 시작 번호를 변경할 때는 새로운 `WORK_DIR`를 사용하고, 재시험 결과를 분리하려면 `RESULT_DIR`도 별도로 지정한다. 기존 작업 상태를 삭제하거나 운영 결과를 덮어쓰지 않는다. `--once`는 한 배치만 실행한다.

후속 아기 데이터 비교에서는 새 영상 6구간 중 임계값 이하 5개/ROI 미검출 1개였으며, 점수가 정지 인형보다 낮은 아기 구간과 높은 구간이 모두 있었다. 기존 파형 773개 재점수화와 새 영상 추론을 구분한 상세 기록은 [BABY_DATA_TEST_20261125.md](BABY_DATA_TEST_20261125.md)에 있다. 정상 수동 승인 기록은 없으므로 임상 성능으로 해석하지 않는다.

## 다음 검증에 필요한 데이터와 구현

사용자는 동일 카메라·거리·조명에서 호흡 움직임을 모사한 비교 영상이 아직 없다고 답했다.

1. 정지 음성 대조군은 위 88~102 재시험으로 확보했다. 추가 촬영에서도 TS 번호와 실제 촬영 구간을 대응시켜 이전 조작 장면이 섞이지 않았는지 먼저 확인한다.
2. 같은 조건에서 규칙적 흉곽 움직임을 모사한 양성 대조군을 확보한다. 정지/주기적 움직임/손 조작·카메라 변화 구간을 분리해 라벨링한다.
3. 정규화 이전의 ROI 움직임, 배경/카메라 움직임, 노이즈 바닥, ROI 신뢰도와 시간별 신호 품질을 보존하고 비교한다. 카메라 조건에 따른 기준을 검증한다.
4. 신호/품질 판정과 기존 파형 패턴 이상 점수를 분리한다. 호흡 움직임 미검출 의심, 움직임/ROI 때문에 판단 불가, 파형 패턴 이상을 구별하며 `unscored`와 기존 상태 계약을 보존한다.
5. 미검토 정상 가정 데이터·영아 ID 병합·학습/생산 전처리 차이도 별도 평가한다. 무호흡 전용 판단은 별도 정답과 검증이 필요하다.

DeepPhys와 AIR-400의 원 논문은 호흡 파형/호흡수 추정을 다룬다. 현재 자체 v2의 무호흡 검출 성능을 대신 검증해 주는 자료가 아니다. [DeepPhys 원 논문](https://openaccess.thecvf.com/content_ECCV_2018/html/Weixuan_Chen_DeepPhys_Video-Based_Physiological_ECCV_2018_paper.html), [AIR-400 원 논문](https://arxiv.org/abs/2512.06888).
