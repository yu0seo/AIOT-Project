# 네 피처 MiniRocket 참가자 5-fold 평가 기준

실행 전에 정한 비교 기준이다. 기존 데이터, 가중치와 결과는 보존한다.

- 대상은 기존 기준과 동일한 P 참가자 20명, no_task 주행 75개다. 기존 제외 참가자/시뮬레이터 이상 주석 규칙을 유지한다.
- 외부 입력은 speed/acceleration/jerk/turn_rate 순서의 네 피처, 10Hz, 3/5/10초다. 7점 인과적 다항식 특징 추출과 signed_log1p 정규화를 유지한다. MiniRocket 내부 합성곱 변환은 새 센서 피처를 추가하는 것이 아니다.
- 공식 aeon 1.6.0의 다변량 MiniRocket 변환기를 사용한다. 10,000 설정은 84의 배수인 실제 9,996개 변환 피처를 생성한다. 입력 축은 공통 (N,T,4)를 aeon의 (N,4,T)로 바꾼다.
- 분류기는 L2 로지스틱 회귀다. 기본 RidgeClassifierCV의 Window별 내부 검증을 사용하지 않는다. 규제 C 후보 0.001/0.01/0.1/1.0은 참가자별 내부 3-fold에서 선택한다.
- 바깥 5-fold에서 매번 16명으로 개발하고 4명을 테스트한다. 모든 참가자는 정확히 한 번 바깥 테스트가 된다. 같은 운전자의 R1/R2와 모든 시나리오/겹치는 Window는 함께 이동한다.
- 안쪽 3-fold의 각 train 참가자로만 원시 피처 정규화, MiniRocket bias, 변환 피처 표준화, 분류기를 맞춘다. 정규화나 변환기를 전체 20명에 먼저 맞추지 않는다.
- 내부 비교는 stride 3초, 최종 바깥 학습/테스트는 stride 1초다. 입력 길이끼리 같은 끝 시각을 사용하며 비교용 초기 기준은 기존 실험과 동일하게 21점으로 고정한다.
- 내부 참가자 macro ROC-AUC 평균으로 길이별 C를 선택한다. 동률이면 더 강한 규제인 작은 C를 고른다. C 선택 후 내부 OOF 점수로 기본 저오탐 임계값(validation Window FPR≤5%)과 보조 balanced accuracy 임계값을 정한다.
- 선택된 C로 바깥 개발 참가자 16명을 전부 다시 학습한 뒤, 이미 정한 임계값을 바깥 테스트 4명에 적용한다. 내부 OOF와 최종 재학습 사이의 점수 분포 차이 때문에 바깥 FPR 5%는 보장하지 않는다.
- 각 바깥 fold의 모델·전처리·임계값과 바깥 테스트 예측을 저장한다. fold별 지표와 20명 전체의 OOF 지표, 참가자 macro 지표, 참가자 군집 bootstrap 95% 구간을 보고한다.
- 서로 다른 fold 모델의 점수 눈금 차이를 고려해 mean fold AUC와 참가자 macro AUC를 주로 해석한다. pooled OOF AUC도 보조로 보고한다. 각 fold에서 고정한 임계값의 실제 FPR/Recall을 집계한다.
- 입력 길이는 각 바깥 개발 집단의 내부 CV 점수로도 선택해 별도 기록한다. 세 길이의 바깥 점수를 본 뒤 최고 길이를 독립 검증된 최적 길이로 주장하지 않는다.
- 이 실험은 같은 IDD를 사용한 반복 연구다. 기존 고정 test 4명이 포함되어 있으므로 완전히 새로운 외부 검증은 아니다. 5-fold는 평가 범위를 넓히는 것이며 실제 데이터 수를 5배 늘리는 것은 아니다.
- 5개의 평가 모델은 서로의 테스트 참가자를 다른 fold 학습에서 보았으므로 이들을 평균해 CV 평가 모델인 것처럼 사용하지 않는다. 최종 배포 모델이 필요하면 별도의 전체 학습/외부 검증이 필요하다.
