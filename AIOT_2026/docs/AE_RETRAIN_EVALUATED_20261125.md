# 평가 방식을 분리한 AE 재학습

2026-11-25. 사용자가 AE 재학습을 요청했고, S09_1의 0~30초는 관찰이 어려워 제외했다. 이후 사용자는 **나머지 데이터는 정상 가정으로 사용**하는 것을 명시적으로 승인했다. 정상 가정 자료의 미검토 상태는 유지한다.

## 실험 설계

- 첫 실험의 목표는 전체 15개 영아 ID에서 2개씩, 약 30개의 정상 가정 30초 구간이다. 전체 로컬 영상 394개/기존 파형 773개를 모두 재추출한 실험이 아니다.
- 기존 `splits.csv`의 역할을 보존하되 metadata의 전체 영아 ID(`AIR_125:S01`, `AIR_400:S01`)를 사용한다. 동일 영아/원본 파일이 train/valid/test에 걸치면 거절한다.
- 이전 추출기의 NPZ와 현 생산 경로의 전처리가 다르므로, 정상 입력을 현재 `DeepPhysRunner` 경로에서 다시 추출한다. 원본 운영 DeepPhys를 사용하며 추가 학습한 student 출력은 섞지 않는다.
- 이미 생산 경로에서 추출/검증한 S05와 S02_008의 teacher raw는 해시 대조 후 재사용한다. 모델의 이상 점수를 정상 라벨 근거로 사용하지 않는다.
- 자동 ROI/유효 파형 추출 실패는 unscored로 기록하고, 같은 영아의 다른 후보를 시도한다. 실패한 입력을 정상으로 바꾸거나 confidence/ROI 설정을 바꿔 통과시키지 않는다. 검출 가능한 영상만 남는 선택 편향을 결과의 한계로 다룬다.
- 사용자가 제외한 구간: AIR_125_S02_001_0_30, AIR_400_S02_1_0_30, AIR_400_S07_01_0_30, AIR_400_S09_1_0_30.

## 라벨과 역할

| 라벨 | 의미 | 복원 학습 사용 |
|---|---|---|
| normal_reviewed_motion | 사용자가 호흡 움직임의 관찰 가능성을 확인한 구간. 임상 정상 정답은 아님 | train 역할인 경우만 |
| normal_assumed | 사용자 승인에 따라 정상으로 가정한 미검토 구간 | train 역할인 경우만 |
| static_simulation | 실제 정지 인형으로 호흡 부재를 모사한 입력. 실제 영아 무호흡이 아님 | 사용하지 않음 |

기존 인형 88~102는 valid의 정지 모사 입력, 새 Kakao 인형 수동 ROI 0~30초는 test의 정지 모사 입력으로 사용한다. 이 영상들은 이전 DeepPhys 개발 과정에 이미 쓰였다. 따라서 새로운 AE의 gradient/선택에서 제외되는 역할과, 프로젝트 전체에서 전혀 보지 않은 임상 외부 테스트라는 주장은 구분한다. 후자의 자료는 현재 없다.

## 재사용한 모델과 변경한 평가

`models/air400_npz_anomaly_v2.py`의 Autoencoder, errors, make_loader, score를 재사용한다. 기존 코드와 운영 checkpoint는 수정하지 않는다. 정상 train만 복원 학습에 사용하고, 파형/BPM 평균·표준편차도 해당 train에서만 계산한다.

정상/정지 모사가 모두 포함된 valid에서 정상 오경보 비율 제한(기본 0.05) 아래 balanced accuracy를 최대화하는 임계값을 고른다. 모델은 valid balanced accuracy를 우선하며 동률일 때 정상 valid 복원 오차로 선택한다. test 점수는 선택이 끝난 후 계산한다. 검증 구간 수가 적으므로 검증상의 오경보 비율 제한이 실제 운영 오탐률 보장을 뜻하지 않는다.

다음 기준선과 비교한다:

- 항상 정상이라고 답하는 기준선. 정상만 있는 테스트에서는 정확도 100%여도 재현율/balanced accuracy를 계산할 수 없다.
- 정상 train 평균 BPM으로부터의 편차만 사용하는 기준선. 파형 AE가 이보다 낫지 않다면 복잡한 파형 모델의 이점을 주장하지 않는다.

정지 모사의 검출률을 실제 무호흡 민감도로 표현하지 않는다. 실제 영아 무호흡 테스트 수는 0이다. 새 파일은 기존 추론기의 model_version=2 형식으로 저장하지만 운영 경로에 자동 연결하지 않는다.

## 실행

```powershell
Set-Location 'C:\Users\OHS\Documents\GitHub\AIOT-Project\AIOT_2026'
$py = 'C:\Users\OHS\miniconda3\envs\air400\python.exe'

# 새 폴더 사용. 정상 가정 승인 없이 실행하지 않음
& $py -B -X utf8 .\prepare_ae_production.py `
  --output .\output\ae_production_dataset_new `
  --per-subject 2 --workers 2 --normal-assumption-approved

# 준비가 완료된 dataset.json을 사용
& $py -B -X utf8 .\retrain_ae_evaluated.py `
  --dataset .\output\ae_production_dataset_new `
  --output .\output\ae_retrained_new --epochs 500 --patience 20 --max-fpr 0.05
```

`per-subject`는 영아별 성공한 구간 수 목표이며 0~30초 한 구간을 서로 다른 영상에서 선택한다. ROI 실패 시 다음 후보를 시도하므로 처리한 원본 영상 수는 성공 수보다 클 수 있다. 성공/실패와 원본 해시, label 상태, split은 dataset.json/progress.json에 남긴다. 새 가중치는 새 출력의 air400_ae.pt에만 저장한다.

## 자동 검증

평가 단위 검사에서 정상만 예측하는 모델의 balanced accuracy가 0.5임을 확인하고, 정상만 있는 평가의 재현율은 null로 처리한다. 동일 점수인 정상/정지 입력을 분리 가능하다고 보고하지 않는다. 문자열 bool/미승인 정상 가정/정지 인형의 train 복원 대상 지정/영아 및 원본 분할 누수를 거절한다. 정상 train 외 자료가 표준화 통계에 들어가지 않는 것도 검사한다.

합성 기능 검사에서는 최종 test 입력만 바꿔도 선택된 가중치·임계값·학습 통계가 바뀌지 않았다. 이는 test를 모델 선택에 사용하지 않는지 확인하는 코드 검사이며 실제 탐지 성능이 아니다. 실제 저장 가중치는 기존 AnomalyV2 추론기로 다시 로드해 test 점수가 일치하는지 검사한다.

## 실제 재학습 완료

데이터: `output/ae_production_dataset_20261125`. 정상 30구간(영아 ID 15개), 정지 인형 2구간이며 ROI 실패 11구간은 별도 기록했다. 정상 중 2개는 사용자 관찰 검토, 28개는 정상 가정이다. 정규화/리샘플링 수치 대조는 최대 차이 2.861e-6으로 허용 2e-5 이내였다.

학습 결과: `output/ae_retrained_evaluated_20261125`. **AE는 기존 가중치에서 이어 학습하지 않고 seed 42로 새로 초기화했다.** 기존 AE 구조와 손실/로더/점수 함수를 재사용했다. DeepPhys는 원본 배포 가중치로 고정해 특징을 만들었으며, 앞선 추가 학습 student 출력은 이 AE 학습에 섞지 않았다.

최대 500회 중 222회에서 조기 종료했고 202회를 선택했다. 임계값은 0.1137420808이다.

| 평가 집합 | 정상 통과 | 정상 이상 후보 | 인형 검출 | 인형 미검출 |
|---|---:|---:|---:|---:|
| valid: 정상 6 + 인형 1 | 6 | 0 | 0 | 1 |
| test: 정상 가정 2 + 인형 1 | 1 | 1 | 1 | 0 |

| 구간 | AE 점수 | 결과 |
|---|---:|---|
| AIR_400_S09_2_0_30, 정상 가정 | 0.98187059 | 이상 후보 |
| AIR_400_S09_3_0_30, 정상 가정 | 0.06917994 | 임계값 이하 |
| 새 Kakao 인형, test | 0.14490736 | 이상 후보 |
| 기존 인형 88~102, valid | 0.04356936 | 임계값 이하 |

valid balanced accuracy는 0.5로 항상 정상 기준선과 같았다. test balanced accuracy는 0.75, 항상 정상 기준선은 0.5였으나 전체 정확도는 둘 다 2/3이었다. test가 3개뿐이고 라벨도 정상 가정/정지 모사이므로 일반화된 무호흡 성능으로 보고하지 않는다. S09_2 점수의 약 93.4%는 BPM 복원 오차에서 발생했다. 실제 임상 이상을 확인한 결과가 아니다.

새 인형 검출만 보고 성공을 선언하지 않는다. 검증 인형 미검출과 정상 가정 시험 구간의 이상 후보 때문에 운영 교체 기준을 충족하지 못했다. 기존 모델과 .env 해시는 보존됐다. 새 checkpoint에는 입력 파이프라인 지문/특징 계약/라벨 건수도 저장했다.

전체 자동 테스트 **66개 통과**. 저장 후 기존 AnomalyV2로 재로드한 최대 점수 차이는 9.54e-7이었다. 상세 근거는 출력 폴더의 `REPORT.md`, `run.json`, `summary.json`, `scores.csv`, `comparison.json`, `learning_and_scores.png`, `checkpoint_provenance.json`이다. 새 가중치는 해당 폴더의 `air400_ae.pt`이며 운영 경로에는 연결하지 않았다.

## 사용자 요청: 추가 학습 DeepPhys와의 5건 조합 시험

`output/model_pair_5case_20261125`에 DeepPhys 49회 + 새 AE 202회 조합 시험을 기록했다. S05/S02_008 아기 구간은 임계값 이하, 정상 가정 S09_2는 이상 후보였다. 기존/새 인형은 모두 임계값 이하였다. 새 인형은 원본 DeepPhys+새 AE에서는 0.14490736으로 이상 후보였으나, 추가 학습 DeepPhys+같은 AE에서는 0.11133257로 임계값 이하가 됐다. 임계값은 0.11374208이다.

새 AE가 학습한 추출기는 원본 DeepPhys이므로 이 조합은 입력 추출기 불일치 시험이며 정식 성능 검증이 아니다. 네 건은 동일 전처리 입력 캐시를 재사용하고 S09_2는 영상부터 다시 전처리했으며, 모델 두 단계는 5건 모두 새로 실행했다. 원본 가중치/운영 경로는 변경하지 않았다. 상세 표·해시·파형은 해당 폴더의 REPORT.md/run.json/summary.json/scores.csv/NPZ에 있다.
