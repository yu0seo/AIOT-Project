# DeepPhys 정지 입력 억제 실험

2026-11-25. 기존 모델과 운영 추론을 보존하는 별도 실험이다.

1. 데이터 목록·검토 기록·손실 함수 구현. 기존 split/전체 영아 ID/원본 해시를 보존하고, 미검토 정상과 정지 인형을 구분한다.
2. 승인된 데이터만 기존 생산 전처리(15Hz, 450프레임, ROI, DeepFlow)로 준비한다. 정지 프레임 복제는 원본 영아의 split을 상속한다.
3. 기존 DeepPhys를 고정 teacher로, 복사본을 student로 사용한다. 정상 출력 보존 MSE와 정지 raw 출력 에너지 손실로 별도 학습한다. 원본 가중치 덮어쓰기를 금지한다.
4. 학습에 쓰지 않은 정상/정지/얕은 움직임/가림/흔들림에 대해 평가한다. 정상 출력을 모두 억제하는 모델은 채택하지 않는다. 같은 정지 영상의 인접 구간은 독립 검증으로 세지 않는다.
5. 검증된 경우에만 호흡 존재 판정과 BPM 거절 경로를 설계한다. 기존 AE의 점수·임계값 유효성을 재평가하고 운영 반영은 별도로 검토한다.

teacher 출력은 기존 동작 보존 목표이며 임상 정답이 아니다. 계획 시작 당시 승인 정상 구간은 0개였고, 이후 사용자 관찰 검토 S05/S02 두 구간과 나머지 데이터의 정상 가정 사용 승인이 추가됐다. 독립적인 실제 정지 촬영 및 흉곽 움직임 양성 대조군은 부족하다. 인형으로 실제 무호흡 민감도를 주장하지 않는다.

## 후속 AE 재학습 (사용자 요청)

현재는 S05 학습/S02 검증의 관찰 가능 구간 2개를 사용자가 검토했다. 이후 사용자는 나머지 데이터를 정상 가정으로 사용하는 것을 명시적으로 승인했다. 관찰이 어렵다고 말한 기존 valid 대표 3구간과 S09_1의 0~30초는 제외한다. 기존 미완료 DeepPhys 평가/운영 과제는 유지한다.

AE 첫 재학습은 전체 15개 영아 ID에서 2개씩의 첫 30초를 현재 생산 전처리로 준비한다. 자동 ROI 실패는 unscored로 보존하고 같은 영아의 다른 후보를 시도한다. 원본 해시/데이터셋 포함 ID/기존 split을 유지하고, 정상 가정·사용자 검토·정지 인형 모사 라벨을 구분한다. 원본 운영 DeepPhys의 출력으로 통일하며 기존 추출기 NPZ와 새 DeepPhys 출력은 섞지 않는다.

기존 Autoencoder/errors/make_loader/score를 재사용한다. train 정상만 복원 손실에 사용하고 표준화도 해당 train에서만 계산한다. 정상/정지 모사를 포함하는 valid에서 정상 오경보 예산과 balanced accuracy로 모델/임계값을 선택한다. test는 선택 후 한 번 평가하고 항상 정상 및 BPM 편차 기준선과 비교한다. 인형은 실제 영아 무호흡 정답이 아니며 이미 개발에 사용된 촬영임을 기록한다. 정상 가정 자료는 검토 완료 정상으로 표시하지 않는다. 새 checkpoint는 새 폴더에만 저장하고 기존 운영 가중치를 교체하지 않는다.

검증: 손실의 진폭 민감도·teacher gradient 차단·입력 거절, 미검토/문자열 bool 거절, 해시 변조와 영아 분할 누수 거절, 기존 서비스 회귀 검사를 수행한다. 각 단계의 실제 완료 근거는 todo.md와 docs/NO_MOTION_FINETUNE.md에 기록한다.

## 사용자 승인 후속 순서 1 → 3 → 4: 호흡 움직임 증거

고정 ROI에서 기존 DeepPhys/공식 EfficientPhys/픽셀 움직임을 비교하고, 신호 존재/BPM 거절을 별도 구현한 후 자동 ROI와 같은 입력의 AE를 연결한다. `docs/RESPIRATION_PRESENCE_EXPERIMENT.md`에 계약과 검증 기록을 둔다. 모델 교체만으로 인형의 양수 BPM이 사라지지 않았고, 실제 통합에서 RGB/BGR 경계 오류를 확인했다. YOLO11m+검출기 색상 보정으로 새 경로를 분리한다. 운영 파일을 바꾸지 않는다.

새 검출기와 색상 보정은 ROI 입력 분포를 바꾸므로 이전 32개 원본 계획의 라벨/분할을 유지하면서 전부 재추출하고 기존 AE 학습기를 재사용한다. 정지 인형은 AE 정상 복원 train에 넣지 않는다. 데이터셋과 체크포인트에 실제 검출기/색상 경로 계약을 기록하고 추론에서 불일치를 거절한다. 개발 보정의 valid는 임계값 선택에 사용되므로 독립 성능으로 보고하지 않는다. S09 약한 움직임의 오경보 후보와 같은 카메라 양성 대조군 부족을 보존하며 운영 채택은 별도 미완료다.
