중요한 구분
이것은 이상 탐지 모델 학습을 위한 추출 후보 데이터입니다. 이상 탐지 모델을 학습한 결과가 아닙니다.
모든 영상에 정상 라벨을 자동 부여하지 않습니다. training_label은 unreviewed입니다.
정상으로 사용할 구간 선정과 별도의 검증/시험 분할은 이후 단계입니다.
원래 공개 HDF5의 정답 호흡 주석을 모델 입력에 섞지 않았습니다.
얼굴 정보는 호흡 모델 입력과 분리된 관측/경고용 정보입니다.

파형 추출
영상 시각을 기준으로 10Hz에 가장 가까운 실제 프레임을 선택합니다.
30초 구간마다 300프레임을 처리하며 남는 180프레임 묶음도 버리지 않습니다.
320x180 -> 공식 Body ROI -> ROI 원래 크기의 DeepFlow -> 공식 정규화 -> 96x96 DeepPhys입니다.
공개 DeepPhys_Deep_Body_best.pth와 원래 YOLO Body/Face 가중치를 사용합니다.
Chest 파인튜닝 가중치를 사용하지 않습니다.
적분·추세 제거(lambda=100) 후 공식 0.3~1.0Hz Butterworth 양방향 필터를 사용합니다.
waveform/detrended_archive는 재검토용 보관 데이터이며 기본 모델 입력은 waveform/filtered입니다.
출력 크기는 임의 단위이며 실제 호흡량이나 가슴 변위의 물리 단위가 아닙니다.
정규화와 필터는 각 30초 전체를 사용하므로 실제 운용에서도 같은 시간 문맥을 사용해야 합니다.

HDF5 주요 항목
  time/time_sec: 구간 내부 시각, 0~29.9초, 300개
  time/source_time_sec: 번호 영상 안에서의 시각
  time/source_frame_index, source_frame_time_sec: 선택된 원본 프레임과 실제 시각
  waveform/network_output: DeepPhys 원시 출력, 300개
  waveform/detrended_archive: 적분·추세 제거 후 필터 전 파형
  waveform/filtered: 공식 필터 후 파형, 300개
  model_inputs/waveform: waveform/filtered의 별칭
  breaths/peak_time_sec: 모델 파형에서 찾은 추정 호흡점 시각
  breaths/interval_sec: 인접 추정 호흡점 사이 간격, 호흡점 수가 K면 K-1개
  breaths/interval_end_time_sec: 해당 간격의 두 번째 호흡점 시각
  breaths/interval_valid: 두 호흡점 모두 필터 경계 2초 밖에 있는지
  features/names: 요약 특성 이름과 배열 순서
  features/summary, summary_valid: 30초 구간의 특성 및 계산 가능 여부
  features/rolling, rolling_valid: 1초씩 갱신하는 호흡 간격 특성
  features/rolling_window_start_sec, rolling_window_end_sec: 실제 계산 범위
  features/rolling_reference_end_sec: 각 rolling 창의 명목상 종료 시각
  features/rolling_available_at_sec: 실제 계산 가능 시각. 전체 30초 정규화·양방향 필터이므로 모두 30초
  time/available_at_source_time_sec: 원본 시각 기준 계산 가능 시각. 각 구간 끝 시각으로 일정
  model_inputs/interval_features, interval_features_valid: 요약 특성과 마스크의 별칭
  quality/source_sample_valid: 시간 정렬 및 원본 프레임 중복 검사
  quality/flow_pair_valid: 다음 프레임이 없는 마지막 광학 흐름 표본은 false
  quality/filter_interior_mask: 2~28초 구간만 true. 양 끝 파형 자체는 삭제하지 않습니다.

호흡 간격 요약 특성
  peak_count: 2~28초 내부의 추정 호흡점 수
  interior_interval_count: 위 호흡점들의 간격 수
  ibi_mean_sec: 평균 호흡점 간격
  ibi_std_sec: 표본 표준편차(ddof=1)
  ibi_cv: 표준편차 / 평균
  ibi_rmssd_sec: 연속 간격 차이의 제곱평균제곱근
  ibi_max_sec: 최대 호흡점 간격
  estimated_bpm_from_ibi: 60 / 평균 간격
  time_since_last_peak_sec: 입력 구간 끝에서 마지막 추정 호흡점까지의 시간
호흡점은 모델 파형의 양의 피크, 최소 간격 1초, prominence=구간 표준편차의 0.25로 고정했습니다.
이 규칙은 추정 피크 추출 규칙이며 실제 호흡 시점을 보증하거나 알림 임계값을 뜻하지 않습니다.
요약은 필터 경계 영향을 줄이기 위해 주로 2~28초를 사용합니다. 마지막 피크 경과시간만 전체 30초 기준입니다.
rolling은 명목상 과거 10초 창을 1초씩 이동하되 계산 범위를 2~28초 내부로 제한합니다.
따라서 처음과 마지막 일부 rolling 창의 유효 길이는 10초보다 짧으며 실제 시작/끝 배열에 기록됩니다.
간격이 없으면 평균 등을 NaN, 두 개 미만이면 표준편차/CV/RMSSD를 NaN으로 기록합니다.
NaN은 0초 간격이라는 뜻이 아닙니다. valid 마스크를 사용하고 학습 분할에서 결측 처리 방법을 정해야 합니다.
여기서 valid는 수치의 유효 여부이며 학습/검증 분할의 validation 라벨을 뜻하지 않습니다.

얼굴 정보
  face/frame_index, time_sec, source_time_sec: 실제 얼굴 검사를 실행한 프레임의 영상 내 시각. 오프라인 작업의 실행 벽시각이 아닙니다.
  face/detected: 1=검출, 0=미검출, -1=실행 오류
  face/confidence, bbox_xywh, rotation_retry_deg: 공식 얼굴 검출기의 선택 결과
  face/observation_valid, partial_error: 실행 성공 여부와 회전 검사 일부 오류
  face/body_valid: 같은 시각의 Body 검출 유효 여부
  face/face_center_inside_body: 얼굴 중심이 Body 안에 있는지. 아기 신원 확인은 아닙니다.
  face/absence_duration_sec: 실제 검사 결과를 바탕으로 한 미검출 지속시간
  face/absence_left_censored: 미검출 시작 전에 얼굴이 보였는지 확인하지 못한 상태
  face/detection_executed_grid: 300프레임 중 실제 검사를 실행한 곳만 true
  face/detected_held_grid: 중간 프레임에 직전 검사 결과를 유지한 배열
  face/absence_duration_held_grid_sec: 직전 검사 상태를 유지하며 계산한 경과시간
Body ROI와 얼굴 박스 좌표는 320x180 전처리 영상 기준입니다. 원본 해상도에 겹쳐 표시할 때는 좌표를 비례 변환하십시오.
10프레임(1초)마다 검사하고 마지막 프레임도 검사하여 보통 30초당 31회 검사합니다.
300개 길이로 유지한 배열이 300회의 새로운 검사를 의미하지 않습니다.
미검출 상태는 같은 번호 영상의 연속 30초 경계에서는 이어집니다.
서로 다른 번호 영상 사이는 연속 촬영임이 보장되지 않으므로 이어붙이지 않습니다.
공식 코드의 Body 대체 박스를 얼굴 검출 성공으로 기록하지 않습니다.
얼굴 미검출은 호흡 정지 라벨이 아닙니다. 옆얼굴과 가림의 원인 구별도 하지 않습니다.

학습 전
  computable 묶음은 요약 입력값이 유한한 후보를 편의상 모은 것입니다. 정상 호흡 라벨이나 높은 관측 품질을 보증하지 않습니다.
  전체 배열에는 rolling 통계가 포함되며, computable 묶음은 파형과 9개 전체 구간 요약 특성만 포함합니다.
  extraction_ok는 파일 추출/시각 정렬/Body 존재 검사이며 정상 호흡 판정이 아닙니다.
  같은 아이·같은 원본 촬영 구간이 학습/검증/시험에 나뉘지 않게 그룹을 확인하십시오.
  AIR-400 그룹은 공개 주석 파일명의 접두어에 따른 보수적 묶음이며 신원을 검증한 값은 아닙니다.
  scaler와 결측값 처리 파라미터는 학습 분할에서만 정하고 실제 입력에도 그대로 사용하십시오.
  전체 1분 파형을 자른 결과와 각 30초 영상을 독립 처리한 결과는 정규화·필터 문맥 때문에 다를 수 있습니다.
