현행 수집: AIR-400 번호 영상 + 확보 가능한 AIR-125 영상, 10FPS / 30초 단위.
현재 실행 조건과 필드 설명은 데이터설명.txt 및 configs/extraction_protocol_30s_v1.json을 참조하십시오.
아래는 이전 후보 설계 기록이며 현재 실행 상태를 뜻하지 않습니다.

이전 수집 설계 v1 · 초기 검토 기록

입력 선정 검토 메모
아래 7개 채널은 초기 추출·보관 후보이며, 모델에 전부 넣기로 확정한 항목이 아닙니다.
필터 전 파형은 보관용으로 남기고 학습에는 필터 후 파형만 넣을 수도 있습니다.
Body 전체의 움직임 통계가 추가 입력으로 유용하다는 점은 현재 실험으로 입증되지 않았습니다.
호흡 간격·주기성 등의 파형 파생 표현, 관측 품질, 국소 호흡 변위 등 대안을 검토 중입니다.
파형 파생 표현은 새로운 독립 측정이 아니며, 부정확한 원파형을 복원하지 못합니다.
국소 호흡 변위는 별도의 영역 추적·신호 추출이 필요한 후보입니다.
단일클래스 방향과 공식 Body용 DeepPhys 기준은 유지하며 대량 추출은 시작하지 않습니다.

모델 방향
단일클래스 이상 탐지 모델에 파형과 움직임 시계열을 함께 입력합니다.
이진분류 전환이나 파형 단독 모델과의 비교는 이번 범위에 넣지 않습니다.

파형 추출 기준
공개 DeepPhys_Deep_Body_best.pth와 원래 Body 검출기를 사용합니다.
320x180 -> Body 영역 -> 해당 영역 크기에서 DeepFlow -> 공식 정규화 -> 96x96 DeepPhys 입력입니다.
Chest 파인튜닝 검출기와 광학 흐름 계산 전 96x96 선축소는 사용하지 않습니다.
움직임 통계는 DeepPhys용 광학 흐름을 정규화하기 전에 복사해 계산합니다.

초기 추출·보관 후보 7개 시계열 채널 (학습 입력 확정 아님)
1. waveform_detrended: 공식 적분·추세 제거 후, 대역 필터 전 파형
2. waveform_filtered: 공식 대역 필터 후 파형
3. motion_speed_mean: 원시 광학 흐름의 크기 평균, ROI 크기와 프레임 시간차로 단위 보정
4. motion_speed_p90: 같은 흐름 크기의 공간 90백분위
5. motion_vx_mean: 수평 흐름 평균, ROI 너비와 프레임 시간차로 보정
6. motion_vy_mean: 수직 흐름 평균, ROI 높이와 프레임 시간차로 보정
7. pixel_change_rate: 같은 영역의 인접 회색조 프레임 평균 절대 차이, 밝기 범위와 시간차로 보정

크기·시간차 보정은 실제 흉부 변위나 호흡량으로의 변환이 아닙니다.
비교·재계산을 위해 보정 전 원시 통계도 보존합니다.
움직임이 얼마 이하이면 이상이라는 문턱값이나 지속시간 판정 규칙은 만들지 않습니다.
지속 패턴은 여러 시점으로 구성된 입력에서 모델이 학습하도록 합니다.

동반 저장 정보
원본/출력 시각, FPS, 프레임 번호, 실제 프레임 시간차, 표본 사용 가능 시각,
Body 검출 유효 여부, 잘라낸 영역, 밝기·선명도, 원본 출처·그룹·모델 해시를 저장합니다.
원시 네트워크 출력과 공개 호흡 주석도 따로 보관하며, 공개 주석은 모델 입력에 섞지 않습니다.
가림 여부는 Body 검출만으로 확정할 수 없으므로 품질 검수 대상입니다.

얼굴 관측 정보 추가 제안
얼굴 검출 유무·검출 신뢰도·박스·실제 검출 실행 시각·추론 실행 상태를 별도로 저장하는 계획입니다.
호흡 단일클래스 모델의 확정 입력이 아니라 최종 관측 안내/알림을 위한 정보입니다.
현재 공개 코드는 얼굴 미검출 시 Body 박스로 대체하므로, 대체 박스를 얼굴 검출 성공으로 기록하면 안 됩니다.
검출한 얼굴이 아기에게 속하는지도 확인해야 하며, 주변 보호자의 얼굴과 혼동하지 않아야 합니다.
실제 검출을 실행한 시각과 값을 다음 프레임들에 채운 시각을 구분합니다.
5초는 사용자가 든 관측 알림 조건의 예시이며 호흡 정지 판정 기준으로 확정하지 않습니다.
옆얼굴·가림·어두움·검출 실패는 얼굴 박스 유무만으로 구분할 수 없습니다.
얼굴 관측과 호흡 판단을 별도로 유지하고, 얼굴이 검출돼도 호흡 경고를 취소하지 않습니다.
이 기능은 설계 단계이며 아직 추출/알림 코드에 구현하지 않았습니다.

시간축·끝부분 보존
원본 FPS와 전체 번호 클립의 실제 길이를 우선 보존합니다.
학습용 공통 시간 간격은 10Hz를 권장하며, 원본 채널에서 시간축을 맞춥니다.
기존 180프레임 묶음에서 버렸던 마지막 부분은 별도 추론해 보존하는 구현이 필요합니다.
마지막 광학 흐름은 대응할 다음 프레임이 없으므로 유효 마스크를 기록합니다.
이는 공식 전처리 순서·가중치를 유지한 데이터 저장/배치 처리 확장입니다.

정규화와 실제 적용
추가 움직임 지표를 매 클립/매 구간마다 Z-score 또는 MinMax로 맞추지 않습니다.
선별된 정상 학습 분할에서 정한 고정 스케일을 실제 입력에도 사용합니다.
공식 DeepPhys 내부 정규화는 유지합니다. 추가 움직임 채널은 그 정규화의 영향을 받지 않습니다.
공식 전체 구간 정규화와 양방향 필터는 오프라인 배치 처리입니다.
학습과 실제 입력의 구간 길이·정규화 문맥을 맞춰야 하며, 이를 바꾸면 파형 재추론이 필요할 수 있습니다.

영상 범위
기존에 논의한 S01~S10 폴더 바로 아래의 번호.mp4 전체가 대상입니다.
원격 목록 확인: 번호 영상 295개, 공개 HDF5가 대응하는 영상 275개, 주석 HDF5 없는 영상 20개.
주석 HDF5가 없어도 모델 추론은 가능하므로 20개도 수집 후보에 포함합니다.
실제 길이·FPS·유효한 영상인지 여부는 영상을 내려받을 때 확인합니다.

학습 데이터 관리
모든 수집 후보에서 추출하되, 모두 정상 학습 자료로 자동 지정하지 않습니다.
호흡 움직임을 관찰할 수 있는 정상 학습 구간의 검수·선별은 별도 단계입니다.
기존 frozen/attenuated 조작 대조와 인형 자료는 정상 학습 자료에 섞지 않습니다.
현재는 이 설계와 원격 파일 목록만 준비한 상태이며, 전체 영상의 새 다운로드/추론은 시작하지 않았습니다.
